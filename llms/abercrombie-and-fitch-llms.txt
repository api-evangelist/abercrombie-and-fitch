# Abercrombie & Fitch Co.

> Abercrombie & Fitch Co. is a global specialty retailer of casual apparel, accessories and
> personal care products, operating the Abercrombie & Fitch, abercrombie kids, Hollister and
> Gilly Hicks brands through e-commerce and physical stores across North America, EMEA and APAC.

Generated by the API Evangelist enrichment pipeline from this repository's apis.yml and probed
artifacts on 2026-08-29. Abercrombie & Fitch does not publish a public API, developer portal,
SDK or machine-readable contract; this file records what the company does publish and what was
probed and not found, so an agent does not go looking for a developer surface that is not there.

## API surface

- No public API. No developer portal, API reference, OpenAPI/AsyncAPI/GraphQL contract, SDK,
  webhook catalog, MCP server or A2A agent card was found on any Abercrombie & Fitch host.
- api.anfcorp.com is a live corporate API gateway (it returns a JSON `{"statusCode":404,
  "message":"Resource not found"}` envelope rather than HTML) but publishes nothing anonymously:
  no root document, no /openapi.json, /swagger.json or /api-docs, and no /.well-known/ document.
- Business-to-business integration with Abercrombie & Fitch runs through EDI trading-partner
  onboarding and affiliate networks, not through a self-serve API program.
